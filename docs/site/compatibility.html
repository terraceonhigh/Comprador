What works with Comprador

Comprador works with devices that speak MTP or PTP, the two USB protocols most non-Apple phones, cameras, and media devices use to expose their files. macOS reads neither on its own, which is the whole reason this app exists.

What is actually supported is decided by libmtp, the open library Comprador uses to talk to the device, not by a fixed list we maintain. So the honest rule is most MTP and PTP devices, not all of them. The trigger is always the same: connect a cable that carries data and, if the device asks, choose File Transfer (sometimes labelled MTP, PTP, or PC / Computer).

Works means we have run it on hardware. Should work means the device uses MTP or PTP and libmtp should mount it, but we have not verified that exact model. If you try one we have not listed, tell us how it went.

What won't work

iPhones and iPads do not speak MTP or PTP, so Comprador can't see them; Apple's own tools already do. There is no wireless mode, USB only. And Comprador never touches ADB or USB debugging, so a device that exposes files only that way is out of scope on purpose.

If your device doesn't show up

Almost always it's the connection mode, not the device. In order of likelihood:

  1. Choose File Transfer on the device. Phones default to charge-only; cameras may sit in a photo-only mode. Pick File Transfer or MTP (on a camera, PC / Computer), unlock the screen, and tap Allow if it asks.
  2. Use a cable that carries data. Many charging cables have no data lines, so the device charges but never appears.
  3. Unplug and plug back in. macOS sometimes grabs a camera or phone for Photos or Image Capture before Comprador can. Reconnecting clears that and lets Comprador claim it.
  4. A very new or unusual device? Comprador talks to devices through libmtp, the open library that knows how to speak to each one. A brand-new model may need a libmtp update before it mounts cleanly. Tell us the model and we'll look.

Still not listed? Click Comprador's menu bar icon and choose Look for a device to force a try on any device that's plugged in.
